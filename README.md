# 太鼓の達人 設置店舗マップ

太鼓の達人ニジイロVerの日本国内の設置店舗マップ

**アクセス**: https://white876765.github.io/taiko_nijiiro_map/

## 概要

このサイトは、太鼓の達人ニジイロVer（以降「ニジイロ」）がプレイできるアーケード店舗を見つけるための**マップサイト**です。プレイヤーの現在地から近い店舗を検索したり、都道府県ごとに設置情報を確認したりできます。

毎日自動で店舗情報が更新されるため、常に最新の設置状況を把握できます。

## 主な機能

### マップ
- 日本全国のニジイロ設置店舗をマップ上に表示
- マップはズームイン・ズームアウトで詳細情報を確認可能
- マーカーはズームレベルに応じて自動的にクラスタリング

### 検索・フィルタリング
- **店舗名検索**：店舗名で絞り込み
- **都道府県フィルタ**：特定の都道府県の店舗のみ表示
- **台数フィルタ**：「台数3台以上」など、機械の台数で絞り込み
- 店舗名・台数を絞り込んでも地図の位置とズームを維持。都道府県を切り替えたときだけ表示範囲を変更

### 現在地検出
- ボタンをクリックすると、ブラウザの位置情報を用いて現在地をマップに表示
- 周辺の設置店舗をすぐに見つけられます

### 統計情報
- 現在表示されている店舗数と合計設置台数をリアルタイム表示

### 更新通知
- 店舗の追加・削除・台数変更を更新状況欄と履歴で確認可能
- 過去7日間の変更履歴を確認可能
- 最終取得日時を日本時間で表示し、最終変更日とは分けて確認可能（日時の記録は修正版での次回正常取得から開始）
- 店舗マーカーはすべて標準の青で表示

## 使い方

1. **マップを見る**
   - ページを開くと、日本全国のニジイロ設置店舗がマップに表示されます

2. **店舗を検索する**
   - 上部の検索ボックスに店舗名を入力して絞り込み
   - ドロップダウンメニューから都道府県を選択
   - スライダーで必要な機械台数を指定

3. **現在地を確認する**
   - 右下の「◎」ボタンをクリックして現在地を表示
   - 周辺の設置店舗が自動的に拡大表示されます

4. **最新の変更を確認する**
   - 右上の更新通知バナーを確認
   - 過去7日間の店舗追加、削除、台数変化の履歴を確認可能

## 更新システム

このマップのデータは毎日自動で更新されます：

- **日次更新**：設置店舗データは毎日自動的に公式情報から取得・更新
- **変更トラッキング**：前日との差分を自動検出
  - 新規追加の店舗
  - 削除された店舗
  - 設置台数の増減
  - 店舗名・住所・都道府県・座標の変更（店舗情報変更として記録）
- **変更履歴**：過去7日間の更新履歴を保存し、いつ何が変わったかを追跡可能

### 取得失敗時の保護と復旧

- 一覧・詳細ページの取得に、このプロジェクトを識別するUser-Agentを設定します。
- 座標は詳細ページのルート検索ボタンから直接取得します。ボタンがない場合は地図iframeの座標を読み取り、両方ある場合は一致を確認します。Chrome・Seleniumは不要です。
- 同一の詳細URL・内容が重複掲載されている場合は1件にまとめます。同じURLの内容が食い違う場合は更新を中止します。
- HTTPエラー、30秒の通信タイムアウト、都道府県ごとの一覧が0件、全国の店舗数が比較元から20%以上減少した場合は更新を中止します。
- 座標取得の失敗・不正な座標・店舗IDの重複も更新を中止する条件です。
- 全店舗の取得と検証が完了するまで、最新版・前回分・差分・履歴は変更しません。
- 最新版が空の場合は前回分、それも空の場合はGit履歴にある最後の空でない店舗一覧と比較します。正常な比較元がなければ中止します。
- GitHub Actionsでは復旧用にGit履歴全体を取得します。ローカルで空データから復旧する場合も、正常だった時点のGit履歴が必要です。

ローカル実行（リポジトリのルートで実行）：

```bash
pip install requests beautifulsoup4
python -m unittest discover -s tests -v
python scripts/fetch.py
```

実行ログにはHTTPステータス、URL、都道府県ごとの取得件数を出力し、失敗時は非ゼロの終了コードで終了します。

### 店舗IDと旧データの移行

- 店舗詳細URLの`loc_id`を`id`として使用し、`loc_id`フィールドにも保存します。店舗名・住所・座標を修正してもIDは変わりません。
- 初回の正常取得時に旧ID（都道府県・店舗名・座標）を照合します。完全一致を優先し、座標だけ・店舗名だけ・住所だけが変わった場合も、残りの情報から一意に対応する店舗を移行します。
- 複数の候補がある場合や、複数の旧店舗が同じ`loc_id`に対応する場合は、データを保存せず中止します。
- 対応先のない旧店舗は削除、新しい`loc_id`の店舗は追加として扱います。複数の情報が同時に変わり照合できない旧店舗は、自動的に同一店舗とは判定しません。
- 移行した比較元データには`legacy_id`を残します。過去の変更履歴は書き換えず、そのまま表示できます。
- 新しい差分には`shop_changed`を追加し、名称・住所・座標等の変更前後を保存します。旧形式の履歴も引き続き読み込めます。

## 注意事項

**店舗情報の正確性について**

このマップに表示される店舗名、住所、座標情報は、公式サイトから自動取得したデータを使用しています。

万が一、表示される情報に誤りや古い情報がある場合は、**公式サイト側のデータが間違っている可能性があります**。
